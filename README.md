# Seoul Traffic Viewer

## Project Overview

Seoul Traffic Viewer is an Object-Oriented Programming (OOP) project that visualizes traffic congestion information in Seoul. Users can view traffic conditions on a map, select a district, and check the congestion level of that area.

## Project Goal

The goal of this project is to develop a simple application that displays traffic congestion information in Seoul and allows users to easily check traffic conditions by district.

## Main Features

* Display a map of Seoul
* Show traffic congestion using colors

  * Green = Low Congestion
  * Yellow = Medium Congestion
  * Red = High Congestion
* Select a district (Gangnam, Songpa, etc.)
* View traffic information for the selected district
* Refresh traffic data
